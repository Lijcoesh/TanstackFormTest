In plaats van het verwijderen van deze folder leg ik uit waarom deze folder er is en waarom hij niet word gebruikt

Ik wou reusable validators maken, maar kwam er achter dat dit niet lekker werkte.

Oude en huidige implementatie:
<form.AppField
    name="username" 
    validators={{
        onChange: ({value}) => {
            if(value.trim() === '') {
                return 'Username is required'
            }
            if(value.length < 3) {
                return 'Username must be at least 3 characters'
            }
            if(value.length > 20) {
                return 'Username must be less than 20 characters'
            }
        },
    }}
>

implementatie met reusable validators
<form.AppField
    name="username" 
    validators={{
        ...validators.isRequired('Username'),
        ...StringValidators.minLength(3, 'Username'),
        ...StringValidators.maxLength(20, 'Username'),
    }}
>

Het probleem met deze implementatie is dat omdat ze alle 3 een onChange hadden, alleen de laatste validatie werd getriggerd.
Ik heb dit proberen op te lossen door de onchange weg te huilen uit de validator code en deze om de validators te zetten op de plekken
waar ze gebruikt werden, maar ook dit werkte niet:
<form.AppField
    name="username" 
    validators={{
        onChange: ({ value }: { value: string }) => ({
            ...validators.isRequired('Username')({ value }),
            ...StringValidators.minLength(3, 'Username')({ value }),
            ...StringValidators.maxLength(20, 'Username')({ value }),
        }),
    }}
>
